# member-360
Member 360: every member and prospect's full relationship with MISMO in one place.
Live at https://resources.mismo.org/member-360/ (sign-in required). It is switched on: this is the
copy the team uses, and changes save to the member data.

Set up the same way as Summit HQ. The member data lives in the private `member-360-data` repo and is
read through the resources.mismo.org relay under the project key `member-360`. No token, secret or
member data is ever kept in this repo.

Who can do what (set per person in People & Access): Admin and Staff can change records; View is
read-only.

Before uploading a new copy of index.html, download the current one from GitHub first and
make changes to that copy, so nothing that changed since is undone.
